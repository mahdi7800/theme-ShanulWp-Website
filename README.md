## 📌 Overview | معرفی

**ShanulWp** is a professional, modern, and multipurpose WordPress theme designed for **news, magazine, educational, video, and personal websites**. It focuses on excellent user experience, clean code, and advanced features.

**ShanulWp** یک قالب حرفه‌ای، مدرن و چندمنظوره برای وردپرس است که برای وب‌سایت‌های **خبری، مجله‌ای، آموزشی، ویدیویی و شخصی** طراحی شده است.

> ⚠️ **Note:** This theme is **not** designed for e-commerce / WooCommerce stores. While WooCommerce can be installed, the theme does not provide dedicated shop styling.
>
> ✅ **Standalone:** ShanulWp works completely without any plugin — all features are built natively.

> ⚠️ **توجه:** این قالب برای فروشگاه‌های اینترنتی / ووکامرس طراحی نشده است. اگرچه ووکامرس روی آن نصب می‌شود، اما قالب استایل اختصاصی برای صفحات فروشگاهی ارائه نمی‌دهد.
>
> ✅ **مستقل:** قالب ShanulWp به صورت کامل و بدون نیاز به هیچ افزونه‌ای کار می‌کند — تمام امکانات به صورت بومی در قالب پیاده‌سازی شده‌اند.

## ✨ Key Features | ویژگی‌های اصلی

### 🗓 Native Jalali (Shamsi) Date Support | پشتیبانی بومی از تاریخ شمسی
- **No plugin required** — built-in Persian calendar support using the lightweight `jdf` library
- Automatic Gregorian → Jalali conversion across the entire site
- Applies to: posts, comments, user dashboard, archives, widgets
- No need for WP-Parsidate, Jalali Date, or any third-party plugin

- **بدون نیاز به افزونه** — پشتیبانی از تقویم هجری شمسی با کتابخانه سبک `jdf`

## 🚀 Installation | نصب

### From WordPress Dashboard | از پیشخوان وردپرس
1. Go to **Appearance → Themes → Add New**
2. Click **Upload Theme**
3. Upload `shanulwp.zip`
4. Click **Activate**
5. Configure via **ShanulWp** menu in dashboard

1. به **نمایش → قالب‌ها → افزودن** بروید
2. روی **آپلود قالب** کلیک کنید
3. فایل `shanulwp.zip` را انتخاب کنید
4. روی **فعال‌سازی** کلیک کنید
5. از منوی **شانول وردپرس** در پیشخوان تنظیمات را انجام دهید

### From GitHub (Developer) | از گیت‌هاب (توسعه‌دهنده)
```bash
cd wp-content/themes/
git clone https://github.com/mahdi7800/theme-ShanulWp-Website.git shanulwp
```
Then activate from WordPress dashboard.

سپس از پیشخوان وردپرس قالب را فعال کنید.

## ❓ FAQ | سوالات متداول

**Q: Is this theme compatible with WooCommerce?**
**A:** No. ShanulWp is designed for news, magazine, and educational websites — **not for e-commerce**. WooCommerce can be installed, but the theme does not provide dedicated shop styling.

**س: آیا این قالب با ووکامرس سازگار است؟**
**ج:** خیر. قالب ShanulWp برای وب‌سایت‌های خبری، مجله‌ای و آموزشی طراحی شده است — **نه برای فروشگاهی**. ووکامرس نصب می‌شود اما قالب استایل اختصاصی برای فروشگاه ارائه نمی‌دهد.

---

**Q: Does this theme require a plugin for Persian dates?**
**A:** No. ShanulWp has native Jalali date support using the `jdf` library. No external plugin needed.

**س: آیا برای نمایش تاریخ شمسی نیاز به افزونه دارم؟**
**ج:** خیر. قالب ShanulWp پشتیبانی بومی از تاریخ شمسی (جلالی) با کتابخانه `jdf` دارد. نیازی به هیچ افزونه جانبی نیست.

---

**Q: Does this theme require any plugins at all?**
**A:** No. ShanulWp works completely standalone. All features (contact form, Jalali dates, user dashboard, like/dislike, bookmark, ads, FAQ, etc.) are built natively into the theme.

**س: آیا قالب نیاز به نصب افزونه خاصی دارد؟**
**ج:** خیر. قالب ShanulWp کاملاً مستقل کار می‌کند. تمام امکانات (فرم تماس، تاریخ شمسی، پنل کاربری، لایک/دیسلایک، بوکمارک، تبلیغات، سوالات متداول و...) به صورت بومی در قالب پیاده‌سازی شده‌اند.

---

**Q: Does it support RTL?**
**A:** Yes, native RTL support for Persian language.

**س: آیا از RTL پشتیبانی می‌کند؟**
**ج:** بله، پشتیبانی بومی از راست به چپ برای زبان فارسی.

---

**Q: Where is Jalali date applied?**
**A:** Posts, comments, user membership date, archives, widgets, and all date displays.

**س: تاریخ شمسی در کدام بخش‌ها اعمال می‌شود؟**
**ج:** مطالب، نظرات، تاریخ عضویت کاربران، آرشیو، ویجت‌ها و تمام بخش‌هایی که تاریخ نمایش داده می‌شود.
